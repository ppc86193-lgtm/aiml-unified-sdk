# AIML Unified SDK

A unified SDK for AIML API that standardizes different model interfaces and provides a consistent, easy-to-use interface for developers.

## 🎯 Purpose

Different AI models often have different API interfaces, parameters, and response formats. This SDK solves that problem by providing:

- **Unified Interface**: One consistent API for all models
- **Easy Model Switching**: Switch between models with a single parameter
- **Automatic Normalization**: Consistent request/response formats
- **Built-in Best Practices**: Authentication, rate limiting, retry logic
- **Comprehensive Logging**: Monitor usage and debug issues

## 🚀 Features

- ✅ Consistent interface across all AIML API models
- ✅ Automatic request/response normalization
- ✅ Built-in authentication and rate limiting
- ✅ Model capability detection and validation
- ✅ Comprehensive error handling
- ✅ Streaming support
- ✅ Usage tracking and monitoring
- ✅ TypeScript support

## 📋 Supported Operations

- Text Generation
- Chat Completion
- Embedding Generation
- Model Information Retrieval
